# Вигадані тестові дані, не люди

Всі `syn_*` ID та числові значення у цій папці — згенеровані або вручну складені приклади. Вони існують виключно для перевірки схеми, навчального пайплайна, UI і звітності. **Ніколи не називати їх реальним UX-дослідженням**. `trials.csv` — демонстраційні записи, які не мають статистичного значення. `feature_rows.csv` отримується скриптом `scripts/generate_synthetic_data.py`. Не завантажувати реальні файли до Git.
