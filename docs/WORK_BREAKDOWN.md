# Розбиття реалізації на практичні кроки

**M1 Research foundation:** контракти подій, feature dictionary, synthetic fixture, group split, offline scorer, unit tests, data/model cards. Вихід: робочий synthetic pipeline й перші таблиці для 2.1–2.4.

**M2 Hybrid policy:** confidence/gain threshold, minimum evidence, cooldown, preserve current, confirm/undo/disable, policy tests, ablation. Вихід: діаграма алгоритму, матриця політик, таблиці для 2.5–2.7.

**M3 Backend:** SQLAlchemy tables, migrations, Pydantic validation, model inference endpoint, opt-in/off/revoke/delete, separate real/synthetic, integration tests.

**M4 Frontend:** 3 accessible layouts, research tasks, feedback/preview/undo, evidence screenshots, keyboard tests.

**M5 End-to-end + documentation:** docker/local launch, reproducible commands, test logs, research report artifacts, diagrams, README, completion status, artifact manifest.

Роби ці етапи в зазначеному порядку, але не зупиняйся після першого без технічного блокування. У разі блокування забезпеч частково завершений і перевірений результат та чітко вкажи причину.
