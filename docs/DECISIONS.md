# Рішення реалізації

- Реальні та synthetic експерименти й артефакти зберігаються окремо.
- На клієнті перший показ завжди статичний. Профіль API створюється лише після добровільної дії.
- Для локального прототипу SQLite дозволяє запуск без Docker; Docker Compose використовує PostgreSQL.
- ML-модель із synthetic даних не застосовується як доказ ефективності для людей. Прогноз її можна показати лише в явно позначеному demo.
- Політика не змінює макет без підтвердження; функції шести віджетів однакові у всіх компонуваннях.
- Термін зберігання подій — 30 днів, очищення виконується при записі нової події та окремою командою обслуговування. Це проєктне рішення, не юридичний висновок.
